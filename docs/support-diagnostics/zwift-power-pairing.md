# Zwift power-source pairing diagnostics

## Zwift waits for pedaling while QZ shows live metrics

### Provide first

- Confirm watts and cadence change inside QZ.
- Provide a screenshot of Zwift's pairing screen, including the selected Power Source and Speed Sensor roles.
- Identify which devices run QZ and Zwift.

### If still unclear

- Check whether QZ's virtual trainer is selected as a speed sensor instead of a power source.
- Retry after clearing stale pairings and restarting the apps; request a short QZ log if the power role is still unavailable.

### Why it matters

- Working telemetry in QZ does not establish that Zwift receives power from the virtual trainer.
- A confirmed case began working after a clean restart and selecting the correct pairing role.
