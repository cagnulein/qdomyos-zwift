# Profiles

## How can I duplicate my current QZ settings into a new profile?

You do not need to configure every setting again. QZ can save the current configuration under a different profile name.

1. Open the QZ **Profiles** page.
2. In **Profile name**, replace the current name with the name you want for the copy.
3. Press **Save**.
4. Restart QZ if prompted or before using the newly saved profile.

Saving with a different name creates a profile from the current settings, so it is useful when you want to keep the same device configuration and make small per-user or per-workout changes without rebuilding the setup from scratch.

Do not use the **+** button for this purpose: that action creates a new profile with default values rather than duplicating the current configuration.
